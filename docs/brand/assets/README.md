# Assets de marca

Colocar aquí los activos exportados de la identidad visual:

- **Logo a color** — versión principal (ej: `logo-color.svg`, `logo-color.png`)
- **Logo B/N** — blanco y negro (ej: `logo-bn.svg`)
- **Logo horizontal** — formato apaisado (ej: `logo-horizontal.svg`)
- **Logo vertical** — formato apilado (ej: `logo-vertical.svg`)

Los componentes del proyecto pueden referenciarlos desde esta ruta (p. ej. en `public` o importando desde el build).
